## 来源与目标

## Task 1：Web 身份、查询与写接口

- [x] **Step 1：写授权 / 版本测试。** 一次性引导凭据只可交换一次，后台 bearer 不在 URL / HTML；会话 HttpOnly / SameSite，写请求检查 Origin / Host / CSRF。无授权、跨源 / CSRF 缺失拒绝且不改数据；同期版本编辑冲突 409，未知 ID / 版本明确未找到。
- [x] **Step 2：实现 Web 引导会话。** 受保护程序打开 loopback 地址的一次性引导 URL，交换会话后跳转清除 URL；控制层授权与浏览器会话分开。校验请求体 / 路径，不能任意读静态资源目录之外文件；不向页面或历史返回真实 key。
- [x] **Step 3：实现列表和详情。** cursor / limit 初始 20、最大 100，稳定排序并绑定筛选；历史按模块 / 状态 / session / episode / record，详情可选历史版本。来源跳转按引用解析，不允许任意绝对文件路径。名称 / 判断 / 假设 / 外扩身份及等待标记展示原版本，不用当前值冒充历史。
- [x] **Step 4：复用归属写入口。** 配置 PUT 返回保存 / 生效版本；知识 / 关系传 record_kind / record_id / expected_version / changes / reason；episode / 认知纠错转任务，返回 task_id / 阶段而不是假保存成功。ID、来源、历史只读；实际结果从任务 / 已提交版本读取。
- [x] **Step 5：运行 Web API 组。**

```powershell
python -m unittest discover -s tests -p 'test_product_web.py' -v
```

预期：`OK`，认证 / CSRF / 版本 / 历史和路由越界用例保护实际契约。

## Task 2：四入口页面与失败交互

- [x] **Step 1：先确认实际页面布局。** 在视觉实现前使用适当设计 Skill，以四入口和已有字段做可审阅布局：导航、列表 / 详情、来源 / 版本、常用字段表单 / 正文文本区、加载 / 错误 / 保存 / 任务反馈。明确键盘与窄屏，不增加图编辑器或复习页面。
- [x] **Step 2：实现原生页面。** HTML / CSS / JS 同源加载，知识正文和外部 / 用户文本通过 `textContent` 或表单 value 编辑 / 展示，不因字符串 Markdown 直接注入 HTML；字段 label / 焦点 / 状态可读。表单显式保存，未修改字段不覆盖；敏感 key 显示“已配置”而非值，编辑 / 删除操作有明确输入语义。用包含脚本标签的合成正文实际检查页面只显示文字、没有脚本执行。
- [x] **Step 3：实现配置状态。** 显示保存版本、正在运行任务配置和待生效值；非法字段保留输入 / 原有效配置并展示字段错误；工作路径收紧的实际停止 / 恢复阶段来自 M01。API key 不进入前端持久缓存 / URL / 日志。
- [x] **Step 4：实现异步纠错 / 编辑。** 202 显示已登记与 task_id，只有成功任务 / 已保存版本显示完成；失败和 409 保留用户输入及原因、不自动合并覆盖。请求绑定路由 / 输入代次，晚返回不覆盖用户更换记录或新编辑；请求期间的编辑内容保留。查询失败提供重试。
- [x] **Step 5：实现历史回查。** 展示当时来源 / 输入输出引用、Prompt / 脱敏配置版本、调用数 / 提交 / 恢复状态；从 episode / 知识 / 关系详情进入对应历史 / 外扩 / 子图 / 筛选。记录修订后仍能访问当时版本和等待说明。

## Task 3：交互、视觉与完整业务验证

- [x] **Step 1：用合成数据浏览四入口。** 覆盖空列表、分页 / 筛选、未知记录、加载错误重试、来源和历史版本跳转；字段一致且不把“无证据”显示为不懂。

- [x] **Step 3：验证异步防覆盖。** 延迟旧详情 / 保存 / 任务响应，在返回前切路由和继续输入，检查新内容不被覆盖、错误仍对应原请求。用浏览器 DOM 自检真实行为，不写只证明 helper 名称的测试。
- [x] **Step 4：验证键盘与窄屏。** Tab / Shift-Tab、Enter / 表单保存、焦点 / label、错误定位、窄屏导航与正文编辑；记录关键截图或录屏，全部合成数据。当前静态页面不引入视觉回归工程。
- [x] **Step 5：决定是否保留前端行为测试。** 保存失败保留输入 / 异步防覆盖若能用标准库调用已隔离的请求状态逻辑稳定验证，则扩展对应契约组；否则保留一次性真实浏览器证据。只有存在持续用户行为回归且现有测试遗漏时再增加最小自动化，不为颜色 / 布局 / DOM 名称引入长期框架。
- [x] **Step 6：同步使用说明。** 写入实际 `start.ps1 -Action Web`、会话失效 / 重开、保存 / 任务 / 冲突差别、来源和历史入口、敏感配置边界；业务语义仍引用归属模块。

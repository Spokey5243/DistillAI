上述材料固定 closed episode 后直接验证 M04 → M05；没有验证真实 Desktop 的切段、Hook 顺序、自然反馈和 compact。M05-R2.3、总体验收 A1.2 / A1.4 仍需相应实测。人工审阅需确认这些关于帮助条件、未决解释、反证据和单次类比的定性表述是否符合预期；不能以任务 succeeded 或 JSON 有效代替。

# DistillAI

DistillAI 从用户与通用 Agent 的日常交互中积累知识及其来源，逐步建立关于该用户理解方式的模型。本词汇表统一项目讨论中的领域用语。

## Language

### 项目角色

**通用 Agent**：用户日常交流与完成任务的 AI 工具，例如 Codex，也是 DistillAI 的接入对象。
_讨论中的别称_：AI 工具。

**接入端**：DistillAI 与某类通用 Agent 之间的连接部分，承担会话材料采集与相关上下文交付。
_讨论中的别称_：前端。

**后台 Agent**：面向同一用户持续维护知识与用户模型的 DistillAI Agent。
_讨论中的别称_：后端。

### 知识与用户状态

**知识**：关于概念、关系、解释及适用条件的内容，具有可追溯的来源。

**知识点**：可独立维护、关联和检索的知识单元；用户对它的理解状态由相关假设及验证证据形成。

**用户模型**：关于用户如何理解、判断及应用知识的持续表征，由用户证据和仍待验证的理解假设组成。

**用户认知地图**：根据用户交流与实际表现，持续形成和修订的关于用户所理解的知识点、知识点之间的联系及个人联想的表征，是用户模型的一部分。

**理解状态**：根据用户历史回复、实际表现及相关理解假设，对用户在特定条件下如何解释和应用知识点形成的当前大致判断。

**理解假设**：对用户理解方式的一种待验证解释；同一组证据可以对应多个竞争假设。

**回忆状态**：用户经过一段时间后回忆或再现已学内容的实际表现，保留当时的任务与帮助条件。

### 材料与证据

**原始材料**：尚未经过 DistillAI 语义整理的会话记录、用户产物或外部资料，保留原始来源和角色。

**episode（交流经历）**：用户围绕某个主题展开的一次连续交流的完整历史及其来源，包含用户表达、Agent 回应和必要上下文。同一主题可以对应多次不同的交流经历。

**派生知识**：从原始材料中提取或综合得到的知识内容，与所依据的原始材料关联。

**用户证据**：用户自己的主张、理由、解释或实际应用，以及这些表现发生时的条件和已获得的帮助。

**验证证据**：用于区分、支持或削弱理解假设的用户表现，既可以来自已有产物，也可以来自后续交互。

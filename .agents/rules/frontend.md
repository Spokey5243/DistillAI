# 前端规则

仅在前端设计、实现或技术选型时生效。

- 当前没有 frontend 工程或已批准的框架；按真实产品需求决定，不默认搬入 Vue、Element Plus 或其他项目依赖。
- 视觉任务先使用当前会话可用的适当设计 Skill，明确布局、信息层级、交互反馈、窄屏和键盘行为，再实现。
- 优先复用当前项目已有组件；不创建没有真实使用需求的设计系统或状态管理层。
- 选定技术栈后同步实际目录、运行、依赖和验证命令；依赖使用对应包管理器，锁文件由工具维护，CI 按锁安装。
- 软件交互与权限需验证实际行为；视觉变化在 PR 中提供关键截图或录屏，非 UI 变化不机械要求截图。
- 保存失败保留用户输入，异步结果不能覆盖更新的路由 / 输入，页面提供加载、错误和重试状态。
- 新增或修改测试先读取 `.agents/skills/test-necessity-review/SKILL.md`。
